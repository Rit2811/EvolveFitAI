# Task 05 - Plan Experience

## Objective
Build a high-quality plan page that clearly presents the generated content.

## Work
- Workout/Meal tabs
- Seven day cards
- Exercise rows
- Intentional rest-day cards
- Meal cards with calorie/protein estimates
- Plan version, date, goal, summary
- Adaptation explanation card
- Responsive layout

## Acceptance criteria
- All seven days render without overflow.
- Rest days are clearly distinguished.
- Plan metadata is visible.
- Empty/loading/error states exist.
- The page is usable on laptop and mobile widths.
