# Task 03 - Onboarding

## Objective
Create a polished multi-step onboarding flow and persist profile data.

## Work
- Personal details
- Goal
- Fitness preferences
- Nutrition preferences
- Review step
- Save to `profiles`
- Mark `onboarding_completed`
- Loading, validation, and error handling

## Acceptance criteria
- Required inputs are validated.
- Equipment and preference controls are easy to use.
- User can navigate backward without losing entered data.
- Saved profile reloads correctly.
- Completion redirects to plan generation or plan page.
