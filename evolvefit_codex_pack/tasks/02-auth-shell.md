# Task 02 - Authentication and App Shell

## Objective
Provide working registration, login, logout, session restoration, protected routes, and the polished application shell.

## Work
- Supabase registration and password login.
- Auth context or equivalent session provider.
- Protected route component.
- Redirect incomplete profiles to onboarding.
- Desktop sidebar and mobile navigation.
- Loading and friendly auth errors.

## Acceptance criteria
- User can register, sign in, sign out, and refresh without losing a valid session.
- Public routes remain accessible.
- Protected routes redirect unauthenticated users.
- Shell contains all required navigation items.
- No password reset or social login is required.
