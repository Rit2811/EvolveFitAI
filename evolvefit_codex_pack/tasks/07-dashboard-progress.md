# Task 07 - Dashboard and Progress

## Objective
Create the primary polished dashboard and concise progress page.

## Dashboard
- Welcome header and goal
- Readiness card
- Today's workout
- Today's meals
- Weekly consistency statistics
- Latest adaptation
- Quick actions

## Progress
- Current weight
- Total check-ins
- Average energy
- Average diet adherence
- Energy, sleep, and adherence trends with Recharts

## Acceptance criteria
- Data comes from Supabase rather than duplicated hardcoded content.
- Missing-data states are attractive and useful.
- Charts render with small datasets.
- Dashboard remains focused and uncluttered.
